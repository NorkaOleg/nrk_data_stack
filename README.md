# nrk_data_stack
NRK Data Stack — инженерные заметки по стеку данных и AI. BI (Superset, QlikSense, Power BI), Data Engineering (Airflow, Kafka, CI/CD), базы данных (PostgreSQL, MS SQL, Hive, ClickHouse), локальные эксперименты (Docker, Qwen, MCP). Показываю реальные сборки, ошибки и решения — для BI‑разработчиков и тех, кто переходит в LLM‑инженерию.
